# B站学梗 · AstrBot 版

从 B站视频的标题、字幕、评论和弹幕中提取网络梗，保存到本插件独立的 SQLite 梗库；也可总结视频。AstrBot 和 MaiBot 的梗库互不共享。

## 安装

在 AstrBot 插件管理中使用仓库地址安装，或把本仓库克隆到 `data/plugins/astrbot_plugin_bilibili_meme`，重载插件。需要 AstrBot 4.24 以上、已配置的聊天模型及可访问的 B站接口。

## 使用

- `/学梗 关键词或BV号`：寻找视频，提取并保存一条梗。
- `/梗库` 或 `/梗库 梗名`：查看最近的梗或精确查询。
- `/总结视频 BV号或链接`：通过字幕、弹幕和评论生成摘要。
- 工具 `bilibili_meme_summary` 和 `bilibili_meme_lookup`：模型可在支持工具调用时使用。
- `/周梗状态`：查看周任务状态。

默认按会话当前模型调用；模型可能是云端服务，B站视频资料会发送给所选模型。只有 B站访问请求发送到 B站；梗库位于 AstrBot 插件数据目录 `memes.sqlite3`。本插件不写入 MaiBot 数据库或 AstrBot 其他插件的数据库。

## 每周自动学习

插件设置中开启 `weekly_enabled`，并填写有效的 `weekly_provider_id`，同时启用 `write_to_db`。默认北京时间周一 9 点后处理上一自然周；需保持 AstrBot 运行。追踪瞎问虾猜丶的《断网补全计划》编号系列及「梗指南」新投稿，按视频去重并从每期提取多个梗。失败保留待处理状态并每 15 分钟重试；停机后补齐已记录进度。首次启用仅处理最近一个完整周。周任务不自动发送群消息。

`inject_matched_memes` 默认关闭。启用后，消息含梗库中的梗名时，最多把三条梗义作为临时内容提供给当前会话模型；梗库在所有会话间共享。此选项需要 AstrBot 4.24 及以上。

字幕获取可能需要 `sessdata`（建议小号）；非空环境变量 `BILI_SESSDATA` 优先于插件配置。凭据在面板中遮罩，但配置文件未加密。没有字幕时只能从标题、评论与弹幕推断，不读取视频画面，不能保证模型判断准确。B站可能风控；周任务和模型请求会产生调用成本。默认限制冷却与并发；请只在可信会话中启用。

## 验证状态

源码包含隔离的单元和模拟宿主测试。功能和具体平台兼容性以目标 AstrBot、模型及 B站账号环境的实际结果为准。请勿将 Cookie、配置和本地数据库提交到公开仓库。
