# 安装与排错

## 安装与配置

1. 在 AstrBot 的插件管理中从仓库安装，或克隆到 `data/plugins/astrbot_plugin_bilibili_meme` 后重载插件。
2. 在插件配置选择是否写入梗库；确认当前会话配置了可用的聊天模型。`/学梗` 和 `/总结视频` 使用当前会话模型。
3. 可选填 B站 SESSDATA 获取需要登录的字幕。面板会遮罩该字段，配置文件本身不加密；环境变量 `BILI_SESSDATA` 非空时优先。不要粘贴凭据到群聊或 issue。
4. 如果需要周任务，开启 `weekly_enabled`、`write_to_db`，在 `weekly_provider_id` 选择可用聊天模型。默认北京时间周一 9 点后处理上一完整自然周；首次启用处理最近完整周。AstrBot 需要保持运行或之后重启来补处理。
5. `/周梗状态` 查看已完成与待处理周；失败每 15 分钟重试，查看 AstrBot 插件日志定位。任务不自动向群聊发送结果。

## 常见问题

- **模型未配置或调用失败**：先在 AstrBot 确认当前会话模型可用；周任务使用单独配置的 provider ID。模型可以是云服务，视频信息会发给该模型。
- **字幕为空或需登录**：确认 SESSDATA 和账号权限；并非每个视频都有字幕。无字幕时根据标题、评论与弹幕推断，不读取视频画面。
- **风控、网络或超时**：降低请求频率、稍后再试；不要关闭 TLS 校验。单个 B站响应大于 8 MiB 会被拒绝。
- **周任务未执行**：检查 `enabled`、`weekly_enabled`、`write_to_db` 和 provider ID。确认时间与运行状态；缺素材、接口错误或写库失败会保留待处理项。
- **更改配置但 Cookie 没变**：检查环境变量 `BILI_SESSDATA`；非空环境变量优先。
- **重装或迁移**：备份 AstrBot 插件数据目录下的 `memes.sqlite3` 和 `weekly_state.json`，不要上传到公共仓库；避免多个实例共享同一状态文件。

模型可能遗漏或误解梗；自动写入的梗库在会话之间共享。强敏感过滤和命中注入均可在插件设置中控制。仅命中梗义注入默认关闭。
